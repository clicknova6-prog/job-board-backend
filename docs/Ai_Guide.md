# AI Development Guide

## Project

- Project: Job Board Backend
- Goal: Production-ready backend for a large-scale job board.
- XML feed: 400k+ jobs, updated hourly.
- Architecture: Feature-based.
- Backend: FastAPI
- Python: 3.14
- Package Manager: uv
- Database: PostgreSQL (planned)

## Rules

- Follow the existing project structure.
- Keep code simple and readable.
- Explain generated code.
- Do not change architecture without explaining why.
- Do not add unnecessary libraries.
- Business logic must not be inside API routes.
